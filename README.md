# AstralPrism DeFi Bot

**Nemotron 3 Super + Jupiter DEX + Solana Devnet**

AI-powered Solana trading bot prototype that uses NVIDIA's Nemotron 3 Super 120B
reasoning model to analyse real-time Jupiter DEX prices and execute demo trades on
Solana devnet.

## Architecture

```
Jupiter Price API  →  Trading Engine  →  Nemotron 3 Super
(real-time quotes)       (Python)       (120B reasoning model)
                            ↓
                    DemoPortfolio           Solana Devnet
                  (simulated trades)    (real wallet + airdrop)
                            ↓
                    FastAPI + WebSocket
                            ↓
                    React-style Dashboard
               (real-time prices + AI signals)
```

## Setup

```bash
cd defi-bot

# Install dependencies
pip install -r requirements.txt

# Configure API key
cp .env.example .env
# Edit .env and set NVIDIA_API_KEY

# Run the bot
cd backend
python main.py
```

Then open http://localhost:8000

## Without an NVIDIA API key

The bot runs in **DEMO mode** — signals are generated by a momentum algorithm
instead of Nemotron. All other functionality (real Jupiter prices, devnet wallet,
portfolio tracking) works normally.

## Key Components

| File | Purpose |
|------|---------|
| `backend/config.py` | Token registry, API endpoints, bot parameters |
| `backend/jupiter_client.py` | Real-time prices + swap quotes from Jupiter V6 |
| `backend/nemotron_client.py` | Nemotron 3 Super signal engine (120B reasoning) |
| `backend/solana_client.py` | Devnet wallet, airdrop, portfolio simulation |
| `backend/trading_engine.py` | Main loop: price → AI → trade → broadcast |
| `backend/main.py` | FastAPI server + WebSocket |
| `frontend/` | Real-time dashboard (Chart.js + WebSocket) |

## Nemotron 3 Super Integration

Model: `nvidia/nemotron-3-super-120b-a12b`  
API: `https://integrate.api.nvidia.com/v1` (OpenAI-compatible)

The bot sends a rich market context including:
- Current prices across SOL/JUP/BONK/WIF
- Price momentum (last 10 ticks per token)
- Portfolio state and recent trades

Nemotron responds with structured JSON:
```json
{
  "signal": "BUY",
  "token": "SOL",
  "confidence": 0.78,
  "targetPrice": 185.50,
  "stopLoss": 178.20,
  "reasoning": "...",
  "marketCondition": "BULLISH",
  "riskLevel": "MEDIUM",
  "suggestedSizePct": 15
}
```

## Extending

- **Add more tokens**: edit `TOKENS` and `TRADING_PAIRS` in `config.py`
- **Real mainnet execution**: replace `DemoPortfolio.execute_demo_trade()` with
  a Jupiter swap transaction using the wallet's secret key
- **Strategy customisation**: modify the Nemotron system prompt in `nemotron_client.py`
- **Add technical indicators**: extend `_build_market_prompt()` with RSI, MACD etc.
